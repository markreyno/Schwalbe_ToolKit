# Pallet Label Printer

Print paired pallet labels (e.g. `YMC 1/10`) to a chosen Windows printer.

## Usage

1. Open **Pallet Label Printer**.
2. Enter company name and total pallets.
3. Select a printer (refresh if none appear).
4. Use **Print labels** or **Print alignment test** for a single diagnostic label.

## Tips

- Labels are generated at the configured label size in the preview.
- If printing fails, check the driver message in the alert and try **Refresh printers**.
