# Counter

A simple tally counter for quick counts on the desktop.

## Usage

1. Open **Counter** from the hub.
2. Tap **Add one** or press **Enter** / **Space** while focused.
3. Use **All tools** and reopen Counter to reset to zero (each session is fresh).

## Notes

- No phone pairing or network setup.
- Closing the tool or navigating away ends the session count.
